# KF-10 Preferensi Pengguna dan KF-19 Recalculate QTO

## KF-10 (UC-07 Atur Preferensi)

Menu **Pengaturan** (Ctrl+3 atau Ctrl+,) menyimpan preferensi di tabel `preferensi_pengguna`
dengan kunci `pref.<nama>`.

| Pengaturan | Nilai bawaan | Dipakai di |
|---|---|---|
| Tema antarmuka | Hitam Kuning | Seluruh aplikasi. Pilihan: **Hitam Kuning** (warna logo Mandajaya), **Terang Emas**, **Biru Malam**, **Terang Biru**. Dipilih lewat kartu pratinjau, diterapkan setelah disimpan. Rincian di `docs/Tema-UI.md` |
| Folder file IFC | Folder Dokumen | Folder awal dialog *Proyek Baru / Import IFC* |
| Folder hasil export | Folder Dokumen | Folder tujuan bawaan dialog *Export RAB* |
| Format file | Excel dan PDF | Pilihan awal di dialog *Export RAB* |
| Isi dokumen | Rekap dan detail per elemen | Pilihan awal di dialog *Export RAB* |

| Langkah UC-07 | Implementasi |
|---|---|
| 1–3 Buka halaman, tampilkan pengaturan | `PengaturanPage.muat()` membaca `muat_preferensi()` |
| 4 Ubah, lalu klik Simpan | Tombol *Simpan Pengaturan* aktif hanya bila ada perubahan. Ada juga tombol *Batalkan Perubahan* |
| 5 Validasi | `PreferensiTidakValid`: folder tidak ditemukan, atau tidak ada format laporan yang dipilih |
| 6 Simpan dan notifikasi | Toast "Pengaturan berhasil disimpan". Bila tema berubah, antarmuka dibangun ulang dengan tema baru |
| Alternatif: Reset ke Default | Konfirmasi "Semua pengaturan akan dikembalikan ke nilai bawaan. Lanjutkan?" |

PPN 11% dan BUK 10% tidak dapat diubah dari halaman ini (KF-11).

Kode: `src/database/preferensi_repository.py`, `src/gui/pengaturan_page.py`, palet `terang` di
`src/gui/tema.py`. Tes: `tests/test_kf10_preferensi.py`.

## KF-19 (UC-03 langkah 7–12: ubah dimensi lalu hitung ulang QTO)

Cara memakai: pada **Hasil Estimasi → Detail per Elemen**, pilih satu baris lalu klik
**Ubah Dimensi** di panel rincian (atau klik dua kali kolom *Elemen / Lantai*).

| Langkah UC-03 | Implementasi |
|---|---|
| 7 Pilih elemen, ubah dimensi | Dialog *Ubah Dimensi Elemen* menampilkan dimensi utama, dimensi turunan, dan nilai semula |
| 8 Validasi | Angka harus > 0 (kemiringan dan luas bukaan boleh 0). Luas bukaan tidak boleh melebihi luas dinding. Kemiringan atap harus < 90° |
| 9 Konfirmasi | "Perubahan dimensi akan memicu kalkulasi ulang QTO. Lanjutkan?" dengan tombol **Ya, Lanjutkan** / **Batal** |
| 10–11 Hitung ulang | `hitung_ulang_elemen()` menyimpan dimensi baru lalu menjalankan rule engine untuk elemen itu saja, dengan konteks bangunan yang sama (lantai dasar, sumber lantai/plafon) |
| 12 Tampilkan hasil | Volume, subtotal, dan total RAB diperbarui. Toast "Perubahan berhasil disimpan". Status baris menjadi **Dimensi diubah**, dan asal dimensi di panel ditandai **Manual** |
| Alternatif A: nilai tidak valid | Pesan galat di dialog, tombol *Hitung Ulang QTO* nonaktif, database tidak berubah |

### Dimensi utama dan turunan (`src/rules/dimensi.py`)

| Elemen | Dimensi utama | Dimensi turunan (asumsi bentuk reguler) |
|---|---|---|
| Pelat | L, B, t | A = L × B, V = A × t, keliling = 2(L + B) |
| Atap | L, B (proyeksi), t, θ | A = L × B / cos θ, V = A × t |
| Dinding | L, H, t, A bukaan | A = L × H − A bukaan, V = A × t |
| Kolom | b, h, H | V = b × h × H |
| Balok | L, b, h | V = L × b × h |
| Fondasi / sloof | L, B, t | V = L × B × t, keliling = 2(L + B) |
| Tiang / sumuran | L, d | V = π d²/4 × L |
| Pintu / jendela | B, H | A = B × H |
| Penutup lantai / plafon / ruang | L, B (H untuk ruang) | A = L × B, keliling = 2(L + B) |

Dimensi turunan dihitung ulang **hanya bila masukannya berubah**. Contohnya, bila hanya tebal dinding
yang diubah, luas Qto dari IFC tetap dipakai dan volume menjadi luas × tebal baru. Luas Qto tidak
diganti menjadi L × H − bukaan.

Elemen berbentuk tidak reguler (misalnya pelat berbentuk L yang tidak punya panjang/lebar di IFC)
tetap bisa dikoreksi dengan mengisi luas atau volume langsung. Pada pelat, atap, dan dinding, mengisi
luas juga menghitung ulang volume.

### Aturan data

- Hanya baris `hasil_estimasi` milik elemen yang diubah yang diganti. Elemen lain tidak tersentuh.
- Volume pekerjaan elemen itu yang sebelumnya diedit manual (KF-6) diganti hasil hitung ulang. Dialog
  memberi tahu jumlahnya sebelum disimpan.
- `elemen_proyek.dimensi_manual = 1`, dan asal setiap dimensi yang berubah di `sumber_dimensi` menjadi
  `manual`.
- *Hitung Ulang dari IFC* mengembalikan semua dimensi ke dimensi model. Konfirmasinya menyebut berapa
  elemen yang dimensinya pernah diubah.

Kode: `src/rules/dimensi.py`, `hitung_ulang_elemen()` di `src/estimasi_service.py`,
`src/gui/dimensi_dialog.py`. Tes: `tests/test_kf19_dimensi.py`.
